# Telegram Sales Userbot

Умный юзербот на базе Telethon и OpenAI для автоматизации продаж в личных сообщениях.

## Установка и запуск

1. Клонируйте репозиторий и авторизуйте новый аккаунт:
   - Склонируйте проект на свой компьютер: `git clone <ссылка_на_ваш_репозиторий>`
   - Перейдите в папку с проектом.
   - ВАЖНО: В целях безопасности файлы авторизации не хранятся в Git. Для подключения нового Telegram-аккаунта вам нужно получить собственные ключи. Перейдите на my.telegram.org, авторизуйтесь и создайте приложение в разделе "API development tools", чтобы получить `API_ID` и `API_HASH`.
   - Создайте в корне проекта файл `.env` и внесите туда свои ключи `API_ID`, `API_HASH` и токен от OpenAI.
   - При самом первом запуске скрипта (после установки библиотек) Telethon попросит вас ввести номер телефона от подключаемого Telegram-аккаунта и код подтверждения. 
   - После успешного ввода программа автоматически создаст файл сессии (например, `my_sales_session.session`), и бот начнет общаться уже от лица этого нового аккаунта. Вводить код при последующих запусках больше не потребуется.
2. Создайте виртуальное окружение: `python -m venv .venv`
3. Активируйте его (Windows): `.venv\Scripts\activate`
4. Установите зависимости: `pip install telethon openai python-dotenv`
5. Создайте файл `.env` в корне проекта по примеру:
API_ID=ваш_api_id
API_HASH=ваш_api_hash
OPENAI_API_KEY=ваш_openai_ключ
6. Запустите бота: `python main.py`
